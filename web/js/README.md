# Browser JavaScript Runtime

This folder contains the browser-side runtime for the Web OMR pipeline.

## Active Benchmark Files

- `app.js`: main app orchestration and shared benchmark helpers.
- `worker-cv.js`: CV-only worker path.
- `worker-yolo.js`: YOLO + CV worker path.
- `wasm-bridge.js`: JavaScript/WASM memory bridge.
- `worker-protocol.js`: worker message protocol.

## Supporting Files

- `camera.js`: camera helper for interactive use.
- `db.js`: IndexedDB/cache helper.
- `preview-print.js`: preview/print workflow.
- `worker-preview-cv.js`: preview worker path.
- `ort.min.js`: vendored ONNX Runtime Web bundle.

## Paper Boundary

Paper latency rows generated by `scripts/drive_batch.py` primarily measure
worker-side fields such as `cpp_ms`, `yolo_ms`, and `worker_total_ms`. If this
runtime changes, rerun the affected Web artifacts before updating the
manuscript.
