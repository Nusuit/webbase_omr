# Archived Resource Profiles

This folder stores older profile/resource captures such as N=54 traces and
earlier Native resource pulls.

These files are archived because they are not the current 179-sheet deployment
resource runs. Some may still be useful as profile-derived context, for example
when explaining older stage-decomposition experiments, but they should not be
mixed into the current paper's main resource table.

If an archived value is reused, label it in the manuscript or notes as a
profile/legacy value and cite the exact file.
