# Legacy Resource Data

This folder contains older resource files that were moved out of the active
resource artifact set after the named-platform cleanup.

Why these files are legacy:

- They predate the current platform-folder convention.
- They were superseded by current folders such as `asus_vivobook/`.
- They may use older sampling sessions or naming conventions.

Use these files only for provenance, regression checks, or explicitly labeled
legacy comparisons. Do not use them for the current paper resource table unless
the manuscript says so.
