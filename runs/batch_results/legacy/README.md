# Legacy Batch Results

This folder contains older Vivobook/PC batch-result JSON files that were moved
out of the active artifact set after the platform naming and rerun cleanup.

Why these files are legacy:

- They predate the current canonical platform naming.
- They were superseded by later `asus_vivobook_*_n179.json` files in
  `runs/batch_results/`.
- They should not be used for manuscript tables unless the text explicitly says
  the value comes from an older/legacy run.

Keep these files for provenance and regression checks. Do not delete them just
to reduce clutter.
